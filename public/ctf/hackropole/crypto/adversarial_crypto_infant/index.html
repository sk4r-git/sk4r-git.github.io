Reverse

RSA is working because of the difficult factorization problem.

  • e is every time known = 65537
  • n = p*q
  • d = e^-1[phi(n)]
  • c = m^e[n]
  • m = c^d[n]

and d is difficult to find because phi(n) = phi(p)*phi(q)

but here phi(n) = n-1 because n is prime.
